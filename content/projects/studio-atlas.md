# Studio Atlas

Studio Atlas needed a digital presence that matched the precision of their architecture work. The result is a minimal, image-forward website with a quiet but confident identity.

## What we did

- Visual identity system
- Responsive website
- CMS integration with Sanity

## Design philosophy

The design uses a strict grid, generous whitespace, and a warm neutral palette. Every interaction is subtle: soft hover states, smooth page transitions, and typography that scales beautifully across devices.
