📁 DATABASE SCHEMA:
===================

POSTS TABLE:
  id              - UUID primary key
  title           - Text, required
  slug            - Text, unique, required
  excerpt         - Text, required (20-300 chars)
  content         - Text, required (markdown)
  cover_image     - Text, nullable
  category        - Text, nullable
  tags            - Text array
  published       - Boolean (default: false)
  created_at      - Timestamp with timezone
  updated_at      - Timestamp with timezone (auto-update)

INDEXES:
  - posts_slug_idx
  - posts_published_idx
  - posts_category_idx
  - posts_created_at_idx
  - posts_published_created_at_idx
  - posts_tags_idx (GIN)

TRIGGER:
  - update_posts_updated_at_trigger (auto-update timestamp)
