NEXT STEPS:
===========

1. CREATE SUPABASE ACCOUNT & PROJECT
   • Go to https://supabase.com
   • Sign up (free account available)
   • Create new project:
     - Name: khizar-arain-portfolio (or your choice)
     - Choose region closest to your users
     - Set a strong database password
   • Wait for project to initialize (~2-3 minutes)

2. GET YOUR CREDENTIALS
   • Go to Project Settings (gear icon, bottom left)
   • Click "API" in left menu
   • Copy:
     ✓ Project URL → NEXT_PUBLIC_SUPABASE_URL
     ✓ Anon/Public Key → NEXT_PUBLIC_SUPABASE_ANON_KEY

3. CREATE .env.local FILE
   • In project root, create file named: .env.local
   • Add these lines:
     NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
     NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key_here
   • Replace with your actual values from step 2
   • This file is in .gitignore (won't be committed to git)

4. CREATE DATABASE TABLE
   • In Supabase Dashboard, click "SQL Editor"
   • Click "New query"
   • Open SUPABASE_SCHEMA.sql (in project root)
   • Copy all the SQL code
   • Paste into Supabase SQL Editor
   • Click "Run" or press Ctrl+Enter
   • Wait for success message
   • The contacts table is now created!

5. START YOUR DEVELOPMENT SERVER
   • Open terminal in project folder
   • Run: npm run dev
   • Open: http://localhost:3000/contact
   • You should see the contact form!

6. TEST THE INTEGRATION
   • Fill out the form:
     Name: "Test User"
     Email: "test@example.com"
     Message: "This is a test message with more than 10 characters"
   • Click "Send Message"
   • You should see: "Thank you! Your message has been sent successfully."
   • Go to Supabase Dashboard
   • Click "Table Editor" → select "contacts"
   • Your test message should appear in the table!

USAGE EXAMPLES:
===============

1. Use in any page:

   import ContactForm from '@/components/ContactForm';

   export default function Page() {
     return <ContactForm />;
   }

2. Use with custom form:

   import { submitContactForm } from '@/lib/contactService';

   const result = await submitContactForm({
     name: 'John Doe',
     email: 'john@example.com',
     message: 'Hello!'
   });

   if (result.success) {
     console.log('Message sent!');
   } else {
     console.error('Error:', result.error);
   }

3. Fetch all contacts (admin):

   import { fetchContacts } from '@/lib/contactService';

   const result = await fetchContacts();
   if (result.success) {
     console.log(result.data); // Array of contacts
   }

ENVIRONMENT VARIABLES:
======================

NEXT_PUBLIC_SUPABASE_URL
├─ Your Supabase project URL
├─ Example: https://abcdefghijkl.supabase.co
└─ Get from: Supabase Dashboard → Project Settings → API

NEXT_PUBLIC_SUPABASE_ANON_KEY
├─ Your Supabase anonymous/public key
├─ This is safe to expose (it's public)
├─ The database password remains private
└─ Get from: Supabase Dashboard → Project Settings → API

⚠️  IMPORTANT: These are prefixed with NEXT_PUBLIC_ so they're exposed in 
              client code (this is intentional and safe with RLS policies)

DATABASE SCHEMA DETAILS:
=======================

Table: contacts

Columns:
├─ id (UUID)
│  └─ Unique identifier, automatically generated
│  └─ Primary key
│
├─ name (TEXT)
│  └─ Contact person's name
│  └─ Required, not null
│
├─ email (TEXT)
│  └─ Contact person's email
│  └─ Required, not null
│  └─ Indexed for faster queries
│
├─ message (TEXT)
│  └─ Contact message content
│  └─ Required, not null
│
├─ created_at (TIMESTAMP)
│  └─ When the contact was created
│  └─ Auto-set to current time
│  └─ Indexed for sorting
│
└─ updated_at (TIMESTAMP)
   └─ When the contact was last updated
   └─ Auto-updated on any change

Row Level Security (RLS) Policies:

Policy 1: "Allow public to insert contacts"
├─ Operation: INSERT
├─ Who: Anyone (unauthenticated users)
├─ Result: ✅ Public can submit contact forms

Policy 2: "Allow public to view contacts"
├─ Operation: SELECT
├─ Who: Anyone (unauthenticated users)
├─ Result: ✅ Public can read contacts

Policy 3: "Prevent public from updating contacts"
├─ Operation: UPDATE
├─ Who: Public users
├─ Result: ❌ Blocked (only admins can update)

Policy 4: "Prevent public from deleting contacts"
├─ Operation: DELETE
├─ Who: Public users
├─ Result: ❌ Blocked (only admins can delete)
